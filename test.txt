

All Allowed Types
templateId (ContentTemplateType)
Value	Purpose
"article"	Formatted rich text / article page
"document_page"	Uploaded document (.pdf, .txt, .doc, .docx) + notes
"video_lesson"	YouTube video guide + structured notes
"multimedia_page"	Mixed sections (headings, text, lists, images, documents, YouTube)


creationMethod (ContentCreationMethod)

Value	Purpose
"type"	Typed directly inside the mobile editor
"paste"	Copied & pasted content (normalized to formatted text/lists)
"upload"	Created primarily by uploading files (.pdf, .txt, .doc, .docx, images)
"mixed"	Combination of typed/pasted text, uploaded files/images, and/or YouTube links
