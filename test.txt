1. Upload Block Media Asset (Images / Documents for Dynamic Pages)
Endpoint: POST /api/v1/media/upload
Auth: Contributor / User (Bearer <accessToken>)
Request Payload (multipart/form-data):
file: Binary file (image/jpeg, image/png, image/webp, image/gif <= 10 MB; or application/pdf, text/plain, application/msword, application/vnd.openxmlformats-officedocument.wordprocessingml.document <= 20 MB)

4. List My Submitted Content Pages
Endpoint: GET /api/v1/content-pages/my-submissions?page=1&limit=20&status=
Auth: Contributor / User (Bearer <accessToken>) — filtered strictly by req.user.id
Request Payload: Query params (page, limit, status: pending | approved | published | rejected)
Response (200 OK): Same paginated { items, meta } envelope as #3 (including status and rejectionReason).
5. Get Content Page by ID
Endpoint: GET /api/v1/content-pages/:id
Auth: Optional (published/approved public; pending/rejected only accessible to owner or admin, else 404)
Request Payload: Path param id
Response (200 OK): Same single-item { success, message, data } object with full blocks[] and metadata as #2.
6. Admin / Content Approver Moderation Queue & Preview
Endpoints:
GET /api/v1/admin/content-pages?page=1&limit=10&status=pending&categoryId=&search=
GET /api/v1/admin/content-pages/:id
Auth: Admin / Content Approver (Bearer <accessToken>, role === 'admin')
Request Payload: Query params (page, limit, status, categoryId, search) or Path param id
Response (200 OK): Paginated { items, meta } for queue listing; single full data object (with blocks[] & metadata) for :id.
7. Admin / Content Approver Approve or Reject Content Page
Endpoint: PATCH /api/v1/admin/content-pages/:id/review
Auth: Admin / Content Approver (Bearer <accessToken>, role === 'admin')
Request Payload (application/json):
json
// Approve
{ "status": "approved" }
// OR Reject
{ "status": "rejected", "rejectionReason": "Missing citation sources in section 2." }
Response (200 OK):
json
{
  "success": true,
  "message": "Content page approved and published successfully.",
  "data": {
    "id": "674a20109b8d4a0012a10010",
    "pageName": "Solar Irrigation Field Guide",
    "status": "approved",
    "rejectionReason": null,
    "publishedAt": "2026-11-28T12:10:00.000Z"
  }
}
