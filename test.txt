Auth: User JWT (Authorization: Bearer <token>)
Query Params: page (number, default 1), limit (number, default 20), status (pending | approved | rejected | published, optional)
Request Body: None

json
{
  "success": true,
  "message": "Success",

1.3 Search History (List / Save / Delete One / Clear All)
Auth: User JWT (Authorization: Bearer <token>)
1. Get History: GET /api/v1/search/history
Response (200 OK):
json
{
  "success": true,
  "message": "Success",
  "data": [
    { "id": "uuid", "query": "sample", "createdAt": "2026-11-26T10:00:00.000Z" }
  ]
}
2. Save Query: POST /api/v1/search/history
Request Body: { "query": "sample" }
Response (201 Created):
json
{
  "success": true,
  "message": "Search query recorded in history.",
  "data": { "id": "uuid", "query": "sample", "createdAt": "2026-11-26T10:00:00.000Z" }
}
3. Delete Single Item: DELETE /api/v1/search/history/:id
Response (200 OK): { "success": true, "message": "Search history item deleted." }
4. Clear All History: DELETE /api/v1/search/history
Response (200 OK): { "success": true, "message": "Search history cleared.", "data": { "clearedCount": 5 } }

1.5 Unified Submission History, Lifecycle Detail & Withdrawal
Auth: User JWT (Authorization: Bearer <token>)
1. Unified History: GET /api/v1/submissions/history
Query Params: status (all | pending | approved | rejected | published), type (all | video | document), page, limit, sortBy (latest | oldest)
Response (200 OK):
json
{
  "success": true,
  "message": "Success",
  "data": [
    {
      "id": "uuid",
      "type": "video",
      "title": "Sample Video",
      "status": "pending",
      "views": 0,
      "category": { "id": "uuid", "name": "Business", "slug": "business" },
      "createdAt": "2026-11-26T10:00:00.000Z",
      "updatedAt": "2026-11-26T10:00:00.000Z"
    }
  ],
  "meta": { "page": 1, "limit": 20, "total": 1, "totalPages": 1 }
}
2. Submission Lifecycle Detail: GET /api/v1/submissions/:type/:id (type: video | document)
Response (200 OK):
json
{
  "success": true,
  "message": "Success",
  "data": {
    "item": { "id": "uuid", "type": "video", "title": "Sample Video", "status": "pending", "createdAt": "2026-11-26T10:00:00.000Z" },

3. Withdraw Pending Submission: DELETE /api/v1/submissions/:type/:id
