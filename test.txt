Coupon will have a unique six digit code with all capital letter and digit.
There must a start and expiry date
value of the coupon can be 10% on services 15% on packages or $5 on service or $25 on packages

When the customer checkout they can select coupon and enter this coupon code to get the discounts
Groomers are normally work based on commissions or hourly salary, so when we create groomer profile we need to set the employment type as commission based or hourly salary.

Also we need to have a settings in payroll settings where we need to configure how the commission will be calculated, whether that is based on original amount (which is before any discount) or after discount amount.
