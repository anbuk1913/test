### Groomer Appointment Book – Multiple Booking Display Enhancement

**Current Issue:**

In the Groomer Appointment Book, when multiple bookings are scheduled for the same date and time slot, the UI does not properly display all bookings.

**Example:**
- Date: 18th November 2026
- Time Slot: 1:00 PM – 2:00 PM
- Total Bookings: 4
- All 4 bookings belong to the same groomer and have the same time slot.

**Expected Enhancement:**

1. All 4 bookings should be displayed within the same time slot in the Groomer Appointment Book.
2. The UI should dynamically accommodate multiple bookings without overlapping or hiding appointment details.
3. Display all bookings clearly with their respective service names, customer names, and booking details.
4. If multiple bookings exist in the same time slot, arrange them in a readable layout (stacked cards or another suitable layout).
5. Ensure the calendar UI remains responsive and visually consistent.
6. Do not break the existing calendar layout, appointment navigation, date selection, or other booking functionalities.

**Important:**

This is a UI display enhancement only. Do not change the existing booking logic, API response, or appointment data. All bookings must be displayed correctly without affecting the current UI design or existing functionality.

**Expected Result:** If 4 bookings exist in the same groomer, date, and time slot, all 4 appointments should be visible clearly in the Groomer Appointment Book without overlapping or UI distortion.
